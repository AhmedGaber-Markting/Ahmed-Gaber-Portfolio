# Ahmed Gaber | أحمد جابر

موقع شخصي لميديا باير وأخصائي إنتاج إبداعي بالذكاء الاصطناعي. يعمل بالعربية والإنجليزية، ويضم المشاريع والتصاميم والفيديوهات والخطط وتقارير الأداء.

## محتويات النسخة

- 24 مشروعًا ودراسة عمل.
- 21 فيديو كاملًا بالصوت.
- 14 خطة واستراتيجية، مع معاينات من الملفات الأصلية.
- 18 عينة تصميم ومحتوى منشور.
- 18 اسم عميل ومشروع داخل شريط متحرك يمكن تشغيله وإيقافه.
- تقارير Vex Agency 1 وVex Agency 2 وVex Agency 3، و28 عينة أداء من Meta وGoogle وSnapchat وTikTok.
- نسخة PDF مرئية من الموقع على هيئة شرائح لقطات شاشة متتابعة، بعد توسيع قوائم المشاريع والتصاميم والفيديوهات والخطط وعينات المنصة المحددة وقت التصوير. لا يُغيّر التصدير ملفات الموقع أو بنيته.
- السيرة الذاتية العربية بصيغة PDF، مع خيار العرض والتنزيل من الموقع.
- ستة تصاميم إضافية لمشروع قلاع ضمن معرض المشروع.

## الرفع على GitHub Pages

1. فك ضغط الحزمة على جهازك.
2. ارفع **محتويات الحزمة كاملة** إلى المستودع. يجب أن يظهر `index.html` في جذر المستودع وبجواره `assets/` وباقي الملفات. ملف ZIP وحده لا يشغّل الموقع.
3. حافظ على مجلدات `assets/` ومساراتها كما هي، وأضف `.nojekyll` أيضًا.
4. من `Settings → Pages` اختر `Deploy from a branch`، ثم الفرع الذي رفعت عليه الملفات (عادة `main`) والمجلد `/(root)`، ثم `Save`.
5. افتح رابط الموقع بعد اكتمال النشر. عند تحديث نسخة سابقة، استخدم تحديثًا كاملًا للمتصفح إذا استمر ظهور التصميم القديم.

عند تحديث مستودع قائم، استبدل الملفات الموجودة بهذه النسخة وارفع الملفات الجديدة معها. لا تضع الحزمة داخل مجلد إضافي في المستودع إذا كنت ستنشر من الجذر.

[شرح إعداد مصدر النشر الرسمي من GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## الملفات الرئيسية

| الملف | الوظيفة |
| --- | --- |
| `index.html` | الصفحة والأقسام والنصوص العربية |
| `portfolio.css` | التنسيق الأساسي والشاشات والمعارض |
| `personal.css` | الهوية الشخصية والصورة وتحسينات العرض |
| `portfolio.js` | المعارض والتقارير واللغة ونوافذ العرض |
| `content.json` | المصدر الأساسي للمشاريع والعملاء والنتائج |
| `content-data.js` | بيانات المعارض الأساسية الخفيفة للتشغيل المحلي وعند فشل تحميل JSON |
| `document-content.js` | النصوص التفصيلية للخطط؛ يُحمّل عند فتح أول خطة فقط |
| `assets/` | الصور والفيديوهات والوثائق والخطوط وتراخيصها |
| `assets/downloads/ahmed-gaber-portfolio.pdf` | البورتفوليو الشخصي المحدّث |
| `assets/downloads/Ahmed-Gaber-CV-ATS-AR.pdf` | السيرة الذاتية العربية بصيغة ATS |
| `tools/sync-content.py` | تحديث نسخة المحتوى الاحتياطية بعد تعديل JSON |
| `tools/validate-site.ps1` | التحقق من مزامنة المحتوى والروابط وأحجام الصور وتصنيفات المنصات |
| `tools/build-portfolio-pdf.ps1` | تصوير الموقع في Chrome وتجميع لقطات الشاشة في شرائح PDF |
| `.nojekyll` | تقديم ملفات الموقع الثابتة على GitHub Pages |

لا يحتاج الموقع إلى npm أو تثبيت مكتبات أو خادم خلفي أو مفاتيح API. خطوط Cairo وManrope وتراخيصها محلية داخل `assets/fonts/`. كل الروابط المحلية نسبية لتعمل داخل مسار مستودع GitHub Pages.

## المعاينة على جهازك

يمكن فتح `index.html` مباشرة؛ النسخة الاحتياطية تعرض المشاريع دون طلب تحميل JSON عبر الشبكة. للمعاينة الأقرب إلى GitHub Pages شغّل داخل المجلد:

```bash
python3 -m http.server 8080
```

على Windows يمكن استخدام `py -m http.server 8080`. افتح `http://localhost:8080`.

## تعديل المحتوى لاحقًا

1. عدّل `content.json`: المشاريع في `projects`، الفيديوهات في `videoSamples`، الخطط في `documents`، التصاميم في `socialSamples`، العملاء في `clients`، والتقارير في `reports`.
2. شغّل `python3 tools/sync-content.py` أو `py tools/sync-content.py` على Windows لتحديث `content-data.js` و`document-content.js`.
3. شغّل `powershell -ExecutionPolicy Bypass -File tools/validate-site.ps1` للتحقق من المحتوى والروابط والأحجام.
4. ارفع ملفات المحتوى الثلاثة والوسائط التي أضفتها. يحمّل الموقع النصوص التفصيلية للخطط عند فتح أول خطة فقط؛ ويظل `content.json` مصدر التعديل.

يتحقق سير GitHub Actions تلقائيًا من هذه الملفات عند كل push وpull request.

لتحديث ملف البورتفوليو PDF كنسخة مرئية من الموقع، شغّل على Windows: `powershell -ExecutionPolicy Bypass -File tools/build-portfolio-pdf.ps1`. يلتقط Chrome الصفحة بالعربية عند مقاس شاشة `1600 × 900`، ويمرّ على كامل الصفحة بعد توسيع قوائم العينات. تُجمع اللقطات كما هي في شرائح PDF عريضة بنسبة `16:9`، من دون تعديل هيكلة الموقع. تظهر التقارير والفلاتر بحالتها المختارة افتراضيًا وقت التصوير. يتطلب ذلك وجود Google Chrome، ويحدّث عدد الشرائح وحجم الملف في ملفي المحتوى.

النصوص العربية الأساسية في HTML، والترجمة الإنجليزية في كائن `en` داخل `portfolio.js`. الحقل `coverPreview` يحدد صورة الخطة في المعرض.

## سلوك الموقع ومصادر الأرقام

التقارير لقطة ثابتة للفترة 1 أبريل إلى 22 أكتوبر 2026، مستخرجة في 23 أكتوبر، ولا تتحدث تلقائيًا. الليدز وبدايات المحادثات قد تتداخل ولا تعني مبيعات أو عملاء فريدين. عينات المنصات الأخرى تحتفظ بفتراتها وعملاتها الأصلية.

الفيديوهات تُفتح داخل الموقع ولا تبدأ بالصوت تلقائيًا. نموذج التواصل يجهّز رسالة واتساب للمراجعة والإرسال. شريط العملاء يتحرك افتراضيًا، ويحترم إعداد تقليل الحركة في الجهاز، مع زر تشغيل وإيقاف دائم.

## تصحيح العرض على الموبايل

- جميع الأقسام والبطاقات تظهر دون انتظار أنيميشن التمرير؛ المؤثر على الشاشات الكبيرة تجميلي، ولا يخفي المحتوى عند تعطل المراقب.
- خطوات خطة الإنتاج والنمو تظهر ببطاقات متساوية العرض، مع العنوان والوصف بجوار الأيقونة، وتدعم العربية والإنجليزية.
- أُصلحت جداول خطة دكتور بلس التي كانت تمنع فتح المعاينة. نصوص الخطة والأرقام محفوظة، ونسخة المحتوى الاحتياطية متزامنة.
- إغلاق المعاينة وإعادة فتحها بسرعة لا يمسح محتوى المعاينة الجديدة.
- عند الرفع، استبدل `index.html` و`portfolio.css` و`personal.css` و`portfolio.js` و`content.json` و`content-data.js` و`document-content.js` معًا. الحزمة الكاملة تتضمن جميع الأصول أيضًا.

تستخدم صفحات معرض قلاع ملفات WebP كاملة ومصغرات WebP بمجموع يقارب 1 MB بدلًا من 11.6 MB من ملفات العرض، مع بقاء ملفات PNG الأصلية مصدرًا للتعديل. تُحمّل الصورة الكاملة عند اختيارها فقط، وتُحمّل صور المعرض كسولًا، ويؤجل مشغل الفيديو تحميل الملف حتى بدء التشغيل. ملفات PDF الأصلية عالية الدقة والفيديوهات محفوظة كما هي؛ عند الانتقال لاستضافة تدعم CDN يمكن نقل الفيديوهات الكبيرة إليها دون تغيير محتوى الموقع.

تمت مراجعة التخطيط داخل Chromium بمحاكاة 13 عرضًا من 320 إلى 1440 بكسل، بالعربية والإنجليزية، مع فحص الأقسام والفلاتر والتقارير والأسئلة الشائعة والمعاينات وحالات تعطل مراقب الحركة وتحميل JSON. المحاكاة لا تمثل اختبارًا على أجهزة فعلية.
